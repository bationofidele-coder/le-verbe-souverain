# Le Verbe Souverain

Académie quotidienne de prise de parole : studio caméra et micro dans la page, évaluation automatique de la voix et du corps sur six critères, vidéothèque annotée, séances de trente minutes au plus (dix en express), semaines renouvelées automatiquement.

Tout est analysé sur l'appareil : aucune vidéo ne quitte le téléphone ou l'ordinateur.

Le mode d'emploi complet est dans `LISEZ-MOI.txt`.
